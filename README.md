# MeChat: React + Socket.IO Chat

A real-time chat app: users join with a name and exchange messages live.

## Features

- Join screen, then the chat room
- Real-time messages over Socket.IO, with join and welcome notifications
- Auto-scroll to the latest message

## Tech stack

React · React Router · Socket.IO (client and server) · Express

## Getting started

```bash
cd server && npm install && npm run dev
cd me-chat && npm install && npm start
```

## Project structure

```
server/    Express + Socket.IO server
me-chat/   React client (Component/Join, Component/Chat)
```
